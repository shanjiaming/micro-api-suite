# Micro API Suite

Unified zero-dependency Node.js microservice hosting 4 RapidAPI products on one instance:

1. `seo-meta-auditor` (`/apis/seo-meta-auditor/openapi.json`)
2. `dns-ssl-intel` (`/apis/dns-ssl-intel/openapi.json`)
3. `rss-to-json-feed` (`/apis/rss-to-json-feed/openapi.json`)
4. `cron-timezone-utils` (`/apis/cron-timezone-utils/openapi.json`)

Set `RAPIDAPI_PROXY_SECRETS` as a comma-separated list of RapidAPI proxy secrets.
